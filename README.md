# 🎮 GameVault SQL Analysis Project
A SQL database project analyzing video game sales, player engagement, and gaming trends using relational database design and analytical queries.



## Overview

GameVault is a relational SQL database project designed to analyze video game sales, player activity, and gaming trends.

The project demonstrates database design, data management, and analytical SQL queries.


## Technologies Used

- MySQL
- SQL
- Relational Database Design


## Database Tables

### Games
Stores video game information including:
- Title
- Genre
- Platform
- Release year


### Players
Stores player information:
- Username
- Country
- Age


### Sales
Tracks:
- Units sold
- Revenue


### Player Activity
Tracks:
- Hours played
- Player engagement


## SQL Skills Demonstrated

- Database creation
- Table relationships
- Primary keys
- Foreign keys
- JOIN statements
- Aggregate functions
- GROUP BY
- Filtering data
- Business analysis queries


## Example Business Questions Answered

- Which games generate the most revenue?
- Which genres are most common?
- How engaged are players?
- Which games have the highest playtime?
